# App Atlas · 我的 Mac 应用图鉴

[打开在线页面](https://outhsics.github.io/mac-app-atlas/)

根据 2026 年 11 月 13 日的本机应用目录扫描整理的静态图鉴，共 215 个条目：145 个用户安装应用、65 个系统目录应用、5 个网页快捷入口。原有 12 个待核实条目已于 2026 年 11 月 14 日补齐用途与来源依据，当前无待核实条目。应用清单仍是 11 月 13 日的扫描快照。

支持名称及用途搜索、用途分类、应用类型筛选、名称及分类排序、待核实筛选、空结果提示、键盘搜索快捷键和响应式布局。无需构建或外部依赖。

## 文件与维护

- `index.html`：完整独立页面，包含样式、交互和内嵌数据，可直接离线打开。
- `apps.json`：公开应用条目，便于查看和维护。修改时应同步 `index.html` 中的 `app-data` 数据。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

GitHub Pages 从 `main` 分支根目录发布。

## 统计与资料边界

扫描覆盖公共应用目录、当前用户应用目录与系统应用目录，以外层 `.app` 包计数；不展开内部 Helper，不包含命令行软件、浏览器扩展、安装镜像、废纸篓或任意其他目录里的应用。安装包存在不代表应用已运行验证。系统目录之外的 Apple 应用仍归入用户安装应用。

用途说明结合公开产品资料、安装包元数据、本机脚本及项目说明与常见用途；无法确认的条目保留待核实标记。卡片提供已核实公开说明的来源链接。同名或多个版本保留独立条目。字符图标不是官方商标。

公开文件不包含个人安装路径、账号、配置、聊天记录、凭据或私人文件。页面不会扫描访问者设备，也不加载分析脚本。

## 验证

已检查数据条数、字段完整性、内嵌数据一致性、JavaScript 语法和公开文件边界，并在 Chrome 验证桌面显示、关键词搜索、空结果提示与待核实筛选。已编写移动端响应式规则；尚未完成手机实机验证。

本次补充：SnapAI 与 SnapAI-Preview 依据安装包中的 AppleScript；榜样教育工作台依据与安装包名称、标识及版本一致的本地项目说明；Xiaomi MiMo 依据安装包产品描述。其余条目结合官方文档或对应项目仓库。`sourceNote` 记录不含私人路径的核实依据，`verifiedOn` 记录核实日期。用途确认不等于逐一启动或业务功能验收。
